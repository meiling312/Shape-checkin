使用说明
1. 在 GitHub 生成 Token（勾选 gist 权限），填到 ①。
2. 点「立即同步」→ 自动创建云档案（② 会显示 Gist ID）。
3. 在另一台设备填相同 Token + 相同 Gist ID，数据即互通。
4. 之后每次打卡/记录都会自动同步，无需手动。
⚠️ Token 只在你自己的浏览器里，用于直连 GitHub；不用时可随时撤销。
